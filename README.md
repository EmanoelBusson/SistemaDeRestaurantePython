# 🍽️ Sistema de Restaurantes | Python

Projeto desenvolvido durante meus estudos na **Alura**, com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO) utilizando Python.

## 📌 Sobre o projeto

O sistema permite cadastrar restaurantes, gerenciar seus estados de funcionamento e registrar avaliações de clientes.

O projeto foi desenvolvido para aplicar conceitos fundamentais da linguagem Python, utilizando classes, objetos, métodos e propriedades.

## 🚀 Funcionalidades

- Cadastro de restaurantes.
- Listagem de restaurantes cadastrados.
- Ativação e desativação de restaurantes.
- Registro de avaliações de clientes.
- Cálculo da média das avaliações.
- Exibição de informações dos restaurantes.

## 🛠️ Tecnologias utilizadas

- Python
- Programação Orientada a Objetos (POO)
